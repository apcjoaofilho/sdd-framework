# examples/

End-to-end runnable demos of the SDD pipeline.

## Planned (v2.0)

- `greenfield-cli-tool/` — start a fresh CLI project, drive RESEARCH → ARCHIVE entirely via cron + skill.
- `existing-project-onboarding/` — apply `scripts/onboard.py` to a representative existing repo.

Each example contains:

- A frozen snapshot of `STATUS.md`, `STATE.json`, `AGENTS.md` at relevant phases.
- A `WALKTHROUGH.md` narrating what happened and why.
- A `Makefile` or shell script to reproduce locally.
